# Third Party Notices

No third-party video, audio, image library, model, or font file is bundled in this package.
The package references Unity Engine, Universal Render Pipeline 17, and the Unity Test Framework provided by the consuming Unity project. Unity shader libraries are included by package path, without redistributing their source.
The optional gallery text uses Unity's built-in LegacyRuntime font at runtime. That font file is not bundled separately.
Sample mathematical media is generated by the project-owned Tools/generate_sample_video.py, with NumPy and the installed FFmpeg encoder as development tools. NumPy and FFmpeg executables are not distributed in this package and are not runtime dependencies.
